# create-slot

Before working with create-slot, read its documentation in this order:

1. If the project has `node_modules/create-slot/dist/docs/SKILL.md`, read it.
   It is the documentation of the installed version: an index of pages with a
   description of each page. Read the pages in
   `node_modules/create-slot/dist/docs/references/` that concern your task, and
   follow their relative links. In a monorepo, look for the package in the
   `node_modules` of the workspace that uses it.
2. Otherwise, read the
   [documentation index](https://r13v.github.io/create-slot/llms.txt) and the
   pages that it lists for your task. These pages describe the latest release.
   If a tool rejects a page Markdown URL, read
   [llms-full.txt](https://r13v.github.io/create-slot/llms-full.txt), which
   contains all pages.

Treat the pages for your task as the source of truth, not your memory of the
API: 4.0 changed it. Use only documented create-slot APIs.
